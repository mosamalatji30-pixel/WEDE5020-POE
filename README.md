# Project Overview

Elegant Drapes is a website concept for a curtain and window-treatment business. The website is designed to help customers explore curtain options, learn about the business, and submit enquiries about products and services.

The website uses a clean and elegant design with a neutral colour palette to create a welcoming and professional appearance.

# Project Objectives

The objectives of the website are to:

- Present the Elegant Drapes business and its services.
- Display curtain options using photographs and descriptions.
- Allow visitors to search and filter curtain products.
- Provide enquiry and contact forms for customer communication.
- Make the website accessible and easy to navigate on different devices.

# Target Audience

The target audience includes homeowners, tenants, interior decorators, and customers looking for curtains or window-treatment solutions for their homes or businesses.

# How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Confirm that the HTML, CSS, JavaScript, and image files are in the correct folders.
4. Open "index.html" in a web browser.
5. Navigate through the website pages and test the interactive features.

# Interactive Features

The website includes or is intended to include:

- Responsive navigation menu
- Curtain search and category filtering
- Gallery lightbox
- Enquiry form validation
- Contact form validation
- Enquiry links that can preselect a curtain type

Form limitation: The current forms prepare an email using the visitor's email application. They do not automatically store or send submissions to a business database.
